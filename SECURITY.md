# Политика безопасности

## Поддерживаемые версии

Исправления выпускаются для последней версии из ветки `main`.

## Как сообщить об уязвимости

Не создавайте публичный issue. Используйте **GitHub → Security → Report a vulnerability**
(private vulnerability reporting) в репозитории проекта или напишите владельцу репозитория.
Укажите версию (`zapret-manager version`), шаги воспроизведения и ожидаемое влияние.
Ответ — в течение 7 дней, исправление критичных проблем — как можно быстрее.

## Что считается уязвимостью

Программа работает как служба LocalSystem, поэтому в первую очередь интересны:

- возможность пользователю без прав администратора повлиять на то, что выполняется от SYSTEM
  (файлы в папке установки, командная строка служб, конфиг, загружаемые релизы);
- обход проверок загружаемых данных (архив релиза, ipset, списки, hosts);
- запись в системные файлы за пределами управляемого блока hosts;
- отказ в обслуживании службы-сторожа от данных, которые может подложить непривилегированный
  пользователь или сеть.

Вне области: компрометация самого репозитория Flowseal (программа ему доверяет по
определению), поведение winws.exe/WinDivert, действия локального администратора.

## Как устроена защита

Модель угроз — [docs/security/THREAT_MODEL.md](docs/security/THREAT_MODEL.md),
