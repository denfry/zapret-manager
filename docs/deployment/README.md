# Установка, обновление, эксплуатация

## Установка

Обычный путь: скачать `zapret-manager.exe` из
[Releases](https://github.com/denfry/zapret-manager/releases/latest), открыть двойным
щелчком (UAC спрашивается один раз на всё меню) и выбрать «Установить». Из командной строки
то же самое:

```powershell
build.cmd                                   # или exe из Releases
dist\zapret-manager.exe install             # спросит UAC
```

`install`:
1. проверяет, что папка (`C:\zapret` или `--dir`) пустая, наша или содержит распакованный
   релиз zapret; если там чужие файлы — отказывается (папка будет закрыта на запись);
2. закрывает папку на запись для всех, кроме SYSTEM и администраторов, владелец —
   «Администраторы» (вложенные файлы получают только унаследованные права);
3. копирует себя, создаёт `config.json` по умолчанию;
4. находит текущую службу `zapret` и её стратегию, скачивает последний релиз, переносит
   `*-user.txt`, game filter и режим ipset;
5. обновляет ipset, списки, hosts; ставит службу `zapret` с той же стратегией и проверяет её,
   при неудаче подбирает;
6. ставит и запускает службу-сторож `zapret-manager` (автозапуск, перезапуск при сбое:
   10 с / 30 с / 2 мин).

Флаги: `--strategy ИМЯ`, `--select`, `--from ПАПКА`, `--no-watchdog`, `--dir ПАПКА`.

## Обновление самого zapret-manager

Скачать новый exe, открыть его и выбрать в меню «Заменить установленный zapret-manager этим
файлом» (пункт виден, когда меню открыто не из exe службы-сторожа) — или выполнить
`install` из нового exe. Служба остановится, exe заменится, настройки и стратегия сохранятся. При старте новая служба проверяет права на папку и исправляет их
(событие в журнале).

## Конфигурация

`C:\zapret\config.json` (перечитывается на каждой проверке; править — с правами
администратора). Поля и значения по умолчанию — в [README](../../README.md#configjson).
Недопустимые значения заменяются значениями по умолчанию с предупреждением в журнале:

| Поле | Допустимо |
|---|---|
| `check_interval_sec` | ≥ 60 |
| `update_interval_hours` | ≥ 1 |
| `min_sweep_interval_min` | ≥ 5 |
| `failures_before_heal` | ≥ 1 |
| `healthy_ratio` | (0; 1] |
| `keep_versions` | ≥ 1 |
| `repo` | `владелец/репозиторий` (`[A-Za-z0-9-]` / `[A-Za-z0-9._-]`) |
| `branch` | `[A-Za-z0-9._/-]`, без `..`, не с `-` |
| `targets[].url` | `http(s)://хост/…`, не больше 50 адресов |

## Права и файлы

| Путь | Кто пишет |
|---|---|
| `C:\zapret\` и всё внутри | SYSTEM, Администраторы (пользователи — только чтение) |
| `C:\Windows\System32\drivers\etc\hosts` | только блок между маркерами `# >>> zapret-manager …` / `# <<< zapret-manager <<<`; копии в `backups\` (10 последних) |
| служба `zapret`, `HKLM\SYSTEM\CurrentControlSet\Services\zapret` | менеджер и `service.bat` |
| служба `zapret-manager` | `install` / `uninstall` |

Свои стратегии (`custom\*.bat`) и правка `config.json` — из редактора, запущенного от
администратора.

## Мониторинг и диагностика

| Что | Как |
|---|---|
| состояние | `zapret-manager status` (без админа) |
| проверка сейчас | `zapret-manager check -v` |
| журнал | `zapret-manager log 100` или `C:\zapret\logs\manager.log` (ротация 2 МБ → `.1`) |
| конфликты, права | `zapret-manager doctor` |
| события | строки `[*]` журнала; последние 8 показывает `status` |

Типичные проблемы:

| Симптом | Причина | Решение |
|---|---|---|
| `install`: «есть посторонние файлы» | папка не отдельная | `install --dir C:\zapret-manager` |
| служба zapret не стартует, код 1060/1072 | WinDivert выгружается / служба помечена на удаление | подождать 10 с, `on`; перезагрузка |
| «сейчас идёт другая операция» | служба подбирает стратегию | команда сама ждёт конца подбора (до 20 минут); Ctrl+C — отменить |
| `state.json не читается … отложен в state.json.corrupt-*` | файл повреждён (сбой питания) | ничего; при желании изучить копию |
| в `doctor`: «папку … может менять не только администратор» | старая установка / правка ACL | перезапустить службу-сторож или `install` |

## Пауза (игры с античитом)

`off [минуты]` — служба zapret останавливается и переводится в ручной запуск (переживает
перезагрузку); сторож включит её по истечении времени. `on` — включить сразу.

## Удаление

```powershell
zapret-manager uninstall          # только служба-сторож; zapret продолжает работать
zapret-manager uninstall --all    # ещё служба zapret, WinDivert и блок в hosts
```

Файлы в `C:\zapret` не удаляются. Чтобы удалить папку обычным пользователем, сначала верните
права: `icacls C:\zapret /reset /T` (от администратора).
