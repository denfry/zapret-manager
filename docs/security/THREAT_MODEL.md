# Модель угроз (STRIDE)

Состояние на 2026-11-08, версия 1.0.0. Найденные и исправленные проблемы —
[docs/engineering/SECURITY_AUDIT.md](../engineering/SECURITY_AUDIT.md).

## Активы

| Актив | Почему ценен |
|---|---|
| A1. Выполнение кода от SYSTEM | служба `zapret-manager` и служба `zapret` (winws.exe) работают от LocalSystem |
| A2. Целостность бинарников и стратегий в `C:\zapret` | они определяют, что запустится от SYSTEM |
| A3. Системный hosts | подмена → перенаправление любых доменов |
| A4. Доступность сети пользователя | WinDivert перехватывает трафик; неверная стратегия ломает интернет |
| A5. config.json / state.json | определяют источник обновлений, паузу, «плохие» версии |

## Границы доверия

```
[GitHub Flowseal] ══TLS══▶ [загрузчик] ──валидаторы internal/*──▶ [C:\zapret, hosts] ──▶ [службы SYSTEM]
[локальный пользователь без прав админа] ──ФС (ACL)──▶ [C:\zapret]        ✗ после исправления
[пользователь] ──UAC──▶ [CLI с правами админа]
[сеть провайдера / DPI] ◀──пробы TCP/TLS──▶ [health]
```

- **TB1 — upstream.** Репозиторий Flowseal доверенный по определению: его winws.exe и
  WinDivert всё равно исполняются от SYSTEM. Якорь доверия — TLS GitHub. Подписи релизов
  Flowseal не публикует.
- **TB2 — локальные пользователи ↔ администратор/SYSTEM.** Граница — ACL `C:\zapret`.
- **TB3 — сеть.** Пробы и загрузки идут через сеть, где возможны DPI-подмены и MITM.
- **TB4 — пользователь ↔ агент/скрипты.** Команды, меняющие систему, требуют UAC.

## Атакующие

| Кто | Возможности | Цель |
|---|---|---|
| T1. Вредонос/пользователь без прав администратора | запись в доступные ему папки, создание папок в `C:\` | повышение до SYSTEM |
| T2. Провайдер/DPI | RST, заморозка, подмена DNS, заглушки с чужим сертификатом | блокировка (не злонамеренность к ПК) |
| T3. Сетевой MITM | перехват трафика без валидного сертификата | подмена загрузок |
| T4. Скомпрометированный upstream | контроль релизов/hosts Flowseal | код от SYSTEM, подмена DNS |

## STRIDE

| Угроза | Сценарий | Мера | Статус |
|---|---|---|---|
| **S** Spoofing | MITM выдаёт себя за GitHub | TLS 1.2+ с проверкой сертификата, редиректы только https | закрыто |
| **S** | Провайдер подменяет DNS Discord | проба классифицирует `dns`/`cert`, стратегия не меняется, совет про DoH | обработано |
| **T** Tampering | T1 подменяет `zapret-manager.exe`/winws.exe/стратегию/config.json в `C:\zapret` | защищённый DACL, владелец «Администраторы», сброс явных ACE (`secureTree`), проверка при старте службы | **закрыто (SEC-01, SEC-02)** |
| **T** | T1 кладёт `netsh.exe` в каталог из PATH | `netsh` по абсолютному пути System32 | закрыто (SEC-03) |
| **T** | архив релиза с `..`, `C:`, ADS, NUL, хвостовыми точками | `safezip.EntryPath` + `filepath.IsLocal` | закрыто |
| **T** | game filter с `--debug=@файл` попадает в binPath | `ValidatePortRanges`: только цифры, запятые, дефисы | закрыто (fuzz) |
| **T** | repo/branch в config.json уводят загрузку на другой путь/хост | `repoRe`/`branchRe`, запрет `..` | закрыто (SEC-07) |
| **T** | T4 публикует вредный релиз или hosts | вне контроля программы; лимиты, валидация формата, откат при ухудшении | принятый риск (SEC-12) |
| **R** Repudiation | непонятно, кто сменил стратегию | события `[*]` в журнале с временем; подделка `[*]` текстом исключена | обработано (SEC-10) |
| **I** Info disclosure | — | секретов нет; журнал содержит только адреса и версии | n/a |
| **D** DoS | zip-бомба / огромный ответ | лимиты: файлов 5000, файл 200 МБ, всего 500 МБ, ответы 256 Б…100 МБ | закрыто (SEC-06) |
| **D** | `.bat` в CP1251 роняет сторож паникой | `asciiLower` (найдено fuzzing'ом) | закрыто (SEC-08) |
| **D** | неверная стратегия ломает интернет | откат binPath, «нет сети — не чиним», рост интервала подборов | обработано |
| **D** | битый state.json стирает паузу/BadVersions | копия `state.json.corrupt-*`, межпроцессная блокировка | закрыто (SEC-14) |
| **E** Elevation | всё из **T** против `C:\zapret` | см. выше; `install` отказывается закрывать папку с чужими файлами | закрыто |
| **E** | CLI переносит в UAC аргументы пользователя | `syscall.EscapeArg`, без shell | ok |

## Остаточные риски

1. **Целостность релиза держится только на TLS GitHub** (SEC-12). Улучшение: сверять SHA-256 из
   `assets[].digest` GitHub Releases API.
2. **Hosts из upstream** может назначить IP любому домену. Это часть доверия к Flowseal (TB1).
3. **Папка релиза вне `C:\zapret`** (старая установка на рабочем столе) остаётся доступной
   пользователю до `install`; `doctor` об этом предупреждает.
4. **Junction внутри `C:\zapret`, созданный до установки,** — `secureTree` не идёт по ссылкам и
   прерывает `install` (fail-closed); разбор — вручную.
