# Контекст проекта

## Зачем

В России Discord и YouTube режутся DPI (ТСПУ). Проект Flowseal/zapret-discord-youtube
даёт `winws.exe` (zapret) + WinDivert и набор «стратегий» (`general*.bat`) — наборов
аргументов winws. Какая стратегия работает, зависит от провайдера и меняется со временем.
Пользователю приходится руками перебирать стратегии, обновлять релизы, списки и hosts.

zapret-manager делает это сам: держит службу `zapret` с рабочей стратегией, обновляет
всё из репозитория Flowseal, проверяет Discord/YouTube настоящими запросами и при поломке
перезапускает, подбирает стратегию или ставит новую версию.

## Пользователи и окружение

- Обычный домашний ПК с Windows 10/11, пользователь — локальный администратор (UAC).
- Сеть — российский провайдер с DPI, иногда VPN (Happ, Amnezia) параллельно.
- Интерфейс — консоль на русском; двойной клик по exe показывает справку и статус.

## Границы ответственности

| Делает zapret-manager | Не делает |
|---|---|
| ставит/перенастраивает службу `zapret` как `service.bat` | не меняет сам winws и стратегии Flowseal |
| качает релизы, ipset, списки, блок hosts | не проверяет UDP/QUIC (голос Discord) |
| проверяет HTTPS-доступность и подбирает стратегию | не управляет VPN и системным прокси |
| закрывает свою папку на запись для не-администраторов | не подписывает и не проверяет подпись бинарников Flowseal |

## Совместимость, которую нельзя ломать

- Файлы настроек zapret остаются там, где их ищет `service.bat` текущего релиза
  (`utils\game_filter.enabled`, `lists\ipset-all.txt`, `lists\*-user.txt`), и меню
  `service.bat` продолжает работать.
- Командная строка службы совпадает с той, что пишет `service.bat` (тест
  `TestMatchesServiceBatInstall`: 176 аргументов ALT3 один в один).
- Значение реестра `zapret-discord-youtube` (имя стратегии) — общее с `service.bat`.
- Форматы `config.json` и `state.json` — обратно совместимы (новые поля только с omitempty/нулевым значением по умолчанию).
