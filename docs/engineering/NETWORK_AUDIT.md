# Сетевой аудит

Описание текущего поведения — [docs/network/README.md](../network/README.md).

Программа — только клиент: два вида исходящих соединений (пробы доступности и загрузки
с GitHub). Серверов, входящих портов, WebSocket, gRPC, балансировки нет — соответствующие
проверки (slowloris, SYN flood, лимиты запросов сервера) неприменимы.

## Находки

### NET-01. Релиз скачивался целиком в память — MEDIUM
- **Где:** `downloadRelease` → `httpGet(…, 100 МБ)` → `io.ReadAll` → `os.WriteFile`.
- **Последствия:** пик памяти службы — до ~2–4× размера архива (рост буфера).
- **Исправление:** `downloader.download` пишет поток в файл с лимитом.
- **Измерение** (`BenchmarkReleaseDownload`, 8 МБ, 3 прогона):

  | Режим | время | память | аллокаций |
  |---|---|---|---|
  | в память (как было) | 10,7–11,1 мс | **33,6 МБ/op** | 630–684 |
  | поток в файл (стало) | 9,9–10,7 мс | **55–59 КБ/op** | 581–584 |

### NET-02. Повторы без разбора причин и без джиттера — LOW
- **Где:** `httpGet`: повтор любых не-200 (кроме 404), пауза 3 с/6 с без джиттера.
- **Последствия:** 403/401 повторялись впустую; одинаковые паузы.
- **Исправление:** повтор только сетевых ошибок, 408/425/429/5xx; 2 с × 2ⁿ⁻¹ + джиттер;
  отмена контекста прерывает паузу. Тесты `TestDownloader*`, `TestBackoffDelayGrows`.

### NET-03. Редирект мог увести на http — LOW (= SEC-09)

### NET-04. Тело не-200 ответа не дочитывалось — INFO
Соединение не возвращалось в пул. Теперь дочитывается до 64 КБ.

### NET-05. Пауза перед повтором DNS не учитывала отмену — LOW
`time.Sleep(500 мс)` в горутине пробы → `sleepCtx`. Остановка службы не ждёт лишнего.

### NET-06. Число параллельных проб не ограничено — LOW
`targets` из config.json — по горутине и соединению на адрес. Теперь ≤ 50 (`maxTargets`),
невалидные URL отбрасываются при загрузке конфига.

### NET-07. MinVersion TLS для загрузок не задан явно — INFO
По умолчанию в Go и так TLS 1.2; задано явно, чтобы не зависеть от GODEBUG.

### NET-08. Проверки только по TCP — INFO (ограничение)
QUIC/HTTP3 и голос Discord (UDP 50000–50100) не проверяются; документировано в README.

## Проверено, проблем нет

| Аспект | Как устроено |
|---|---|
| Таймауты проб | `context.WithTimeout` на адрес + `conn.SetDeadline`; DNS на весь бюджет; connect ≤ 4 с |
| Утечки соединений | `defer conn.Close()`, `defer resp.Body.Close()`; `Connection: close` |
| Чтение тела | `io.LimitReader(48 КБ)` — ни проба, ни загрузка не читают неограниченно |
| TLS проб | `ServerName`, проверка сертификата, ALPN http/1.1, ≥ 1.2 |
| IPv4/IPv6 | оба; IPv4 первым (у части провайдеров IPv6 сломан), максимум 2 адреса |
| Прокси | пробы — без прокси (намеренно), загрузки — из окружения |
| DNS rebinding / SSRF | адреса проверок задаёт только администратор; внешних URL из сети программа не принимает |
| Таймауты загрузок | dial 15 с, TLS 15 с, заголовки 30 с, весь запрос 3 мин |
| Ограниченность повторов | 3 попытки; подборы ограничены `min_sweep_interval_min` и ростом интервала |

## Тесты сетевого поведения

`health_test.go` — локальные серверы, имитирующие DPI: заморозка на 20 КБ, RST на ClientHello,
зависший TLS, молчащий сервер, чужой сертификат, отказ в соединении, отмена, параллельность.
`release_test.go` — повторы, лимиты (с Content-Length и chunked), редиректы, отмена в паузе,
запись в файл. `update_test.go` — весь поток обновления против локального «GitHub».
`net_test.go` (`ZM_NET=1`) — то же против настоящего GitHub (прогнан 2026-11-08: PASS, 3,5 с).
