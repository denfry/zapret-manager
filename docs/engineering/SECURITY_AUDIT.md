# Аудит безопасности

Модель угроз — [docs/security/THREAT_MODEL.md](../security/THREAT_MODEL.md).
Инструменты: ручной разбор кода, проверка ACL на живой системе, govulncheck v1.9.0,
gosec v2.30.0, golangci-lint v2.15.0 (gosec, errorlint, nilerr, …), gitleaks v8, native
Go fuzzing (8 целей).

## Находки

### SEC-01. Папка установки доступна на запись любому пользователю → SYSTEM — HIGH
- **CWE-732, CVSS 3.1 7.8** (AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H).
- **Где:** `cmdInstall` создавал `C:\zapret` через `os.MkdirAll`.
- **Причина:** папка в корне диска наследует от `C:\` ACE «Прошедшие проверку: изменение»
  (`(OI)(CI)(IO)(M)`). Проверено `icacls C:\zapret` на машине разработчика.
- **Последствия:** любой пользователь/вредонос без прав администратора подменяет
  `zapret-manager.exe` (служба LocalSystem), `releases\*\bin\winws.exe`, стратегию или
  `config.json` (`repo` → свой релиз) и получает выполнение кода от SYSTEM без UAC.
  Через `custom\*.bat` можно передать winws `--debug=@файл` — запись произвольных файлов от SYSTEM.
- **Исправление:** `security.go`: `secureTree` — защищённый DACL `SY:FA, BA:FA, BU:RX`
  (наследуется вглубь), сброс явных ACE у вложенных объектов, ссылки не обходятся;
  `install` применяет его до копирования exe; служба при старте проверяет `checkDirACL` и
  исправляет (`ensureRootSecure`); `doctor` показывает проблему.
- **Проверка:** `TestSecureTreeLocksOutNonAdmins` (без прав администратора запись и создание
  файлов в закрытой папке запрещены, чтение работает; явный ACE «Все: полный» на вложенном
  файле сброшен).

### SEC-02. Владелец заранее созданной папки сохраняет права — MEDIUM
- **Где:** то же. **Причина:** владелец объекта всегда имеет WRITE_DAC.
- **Последствия:** пользователь, создавший `C:\zapret` до установки, вернул бы себе запись
  после любого DACL.
- **Исправление:** владелец корня и всего внутри — `BUILTIN\Administrators` (`O:BA`);
  `checkDirACL` сообщает о недоверенном владельце.

### SEC-03. Системная программа ищется через PATH — MEDIUM
- **CWE-427.** **Где:** `enableTCPTimestamps` → `exec.Command("netsh", …)` от SYSTEM/админа.
- **Последствия:** `netsh.exe` в каталоге из PATH, доступном пользователю, выполнился бы с правами SYSTEM.
- **Исправление:** `systemBinary` (`GetSystemDirectory`), таймаут 30 с, ошибка не глотается.

### SEC-04. Путь к hosts из переменной окружения — LOW
- **Где:** `hostsPath` → `os.Getenv("SystemRoot")`. **Исправление:** `GetSystemDirectory`.

### SEC-05. Достижимые уязвимости стандартной библиотеки — MEDIUM
- **Где:** toolchain go1.26.1; 23 уязвимости (GO-2026-4866, -4870 и др.) с трассами из
  `checkTarget`, `httpGet`.
- **Исправление:** `toolchain go1.26.10` в go.mod; `govulncheck`: «No vulnerabilities found».
  В CI — еженедельный прогон.

### SEC-06. Распаковка: молчаливое обрезание и отсутствие общих лимитов — MEDIUM
- **Где:** `extractZipFile` (`io.LimitReader(rc, 200 МБ)` без ошибки), нет лимита суммы и
  числа файлов; не отвергались зарезервированные имена (`NUL`) и компоненты с хвостовыми
  точками/пробелами (Win32 их срезает).
- **Последствия:** битый релиз мог пройти проверку; zip-бомба — заполнение диска.
- **Исправление:** `internal/safezip`: 5000 файлов, 200 МБ на файл, 500 МБ всего, превышение —
  ошибка `ErrLimit`; `filepath.IsLocal`; `FuzzEntryPath`.

### SEC-07. repo/branch из config.json не проверялись — LOW
- **Где:** `rawURL`, URL релиза. **Последствия:** вместе с SEC-01 — смена источника кода для
  SYSTEM; отдельно (после SEC-01 файл только для админов) — защита от опечаток/инъекции пути.
- **Исправление:** `repoRe`, `branchRe`, запрет `..`; недопустимое — значение по умолчанию и
  предупреждение. Также проверяются `targets` (схема, хост, ≤ 50).

### SEC-08. Паника на стратегии в CP1251 — MEDIUM (DoS)
- **Найдено fuzzing'ом** (`FuzzExtractWinwsArgs`): `strings.ToLower` заменяет невалидный UTF-8
  на 3-байтовый U+FFFD, индекс в нижнем регистре не соответствует исходной строке →
  `slice bounds out of range`.
- **Последствия:** `custom\*.bat`, сохранённый в Блокноте в ANSI с кириллицей в заголовке
  `start "…"`, ронял сторож при каждом подборе (перезапуск по кругу); `ExeFromCmdline`
  возвращал неверный путь.
- **Исправление:** `asciiLower` (сохраняет длину); регрессионный тест
  `TestExtractWinwsArgsCP1251`; корпус в `testdata/fuzz`.

### SEC-09. Редирект загрузки мог понизиться до http — LOW
- **Исправление:** `httpsOnlyRedirect`, ≤ 10 редиректов; тест `TestDownloaderRejectsDowngradeRedirect`.

### SEC-10. Подделка событий журнала — LOW
- **Где:** `lastEvents` искал « [*] » в любом месте строки. Текст из ответа сервера мог
  показаться в `status` как событие.
- **Исправление:** `parseEventLine` — уровень строго после метки времени.

### SEC-11. `uninstall --all` удалял записи hosts после незакрытого маркера — LOW
- **Где:** `removeHostsBlock` удалял всё до конца файла; `mergeHosts` в том же случае — ничего
  (несогласованность). **Исправление:** одно правило `blockRange`; тест `TestRemoveBlockUnterminatedKeepsUserLines`.
  Также upstream-hosts со строкой-маркером теперь отвергается (иначе ломалась идемпотентность).

### SEC-12. Целостность релиза держится только на TLS GitHub — INFO (принятый риск)
- Flowseal не публикует подписи. Компрометация репозитория = код от SYSTEM — как и при ручной
  установке zapret. **Рекомендация:** сверять `assets[].digest` (SHA-256) из GitHub Releases API.

### SEC-13. Копия hosts могла не создаться, а hosts — перезаписаться — LOW
- **Где:** `writeHosts` игнорировал ошибку записи копии. **Исправление:** без копии hosts не пишется.

### SEC-14. Испорченный state.json затирался пустым состоянием — LOW
- **Последствия:** потеря `paused_until` (zapret включался посреди игры с античитом), `bad_versions`
  (повторная установка плохой версии). **Исправление:** копия `state.json.corrupt-*`, предупреждение.

### SEC-15. killProcesses завершает все winws.exe в системе — INFO
Повторяет поведение `service.bat`; документировано.
