# Архитектурный аудит

Текущее устройство — [docs/architecture/README.md](../architecture/README.md).

## Исходное состояние

Один пакет `main` (10 файлов): CLI, служба, бизнес-логика, системные вызовы и разбор
внешних данных (.bat, hosts, zip, версии, game filter, списки) вперемешку. Глобальное
изменяемое состояние — только `commands` (инициализация) и `dlClient`. Циклических
зависимостей нет (один пакет). Конфигурация и состояние — JSON-файлы. Внешних интерфейсов,
БД, контейнеров нет.

## Находки

### ARC-01. Парсеры недоверенных данных не отделены от системного кода — MEDIUM
- **Где:** `strategy.go` (разбор .bat, game filter), `hosts.go` (слияние), `release.go` (zip, версии, списки).
- **Причина:** рост одного пакета без границ.
- **Последствия:** нельзя fuzz-ить и тестировать без Windows-API; граница доверия не видна;
  ошибки разбора (см. SEC-08) не находились.
- **Исправление:** вынесены чистые пакеты `internal/batch`, `hostsfile`, `safezip`, `version`,
  `zapretfmt`, `textutil` без `x/sys/windows` и без ввода-вывода (кроме safezip). Fuzz-цели — 8.
  Покрытие этих пакетов 82–100 %.

### ARC-02. Решения перемешаны с механизмами — LOW
- **Где:** условие отката релиза внутри `updateRelease`, сводка проверки внутри `runHealth`.
- **Последствия:** самые рискованные решения не тестировались.
- **Исправление:** `releaseIsWorse` и `summarize` — чистые функции с табличными тестами.

### ARC-03. Неявная зависимость от глобального HTTP-клиента — LOW
- **Где:** `dlClient`, `httpGet`.
- **Последствия:** нельзя протестировать политику повторов и поток обновления.
- **Исправление:** тип `downloader` (клиент, число попыток, пауза); `App.downloader`,
  `App.rawBase/githubBase` подменяются в тестах. По умолчанию — общий клиент с пулом.

### ARC-04. Межпроцессная согласованность state.json — MEDIUM
См. REL-01 в [TECHNICAL_DEBT.md](TECHNICAL_DEBT.md).

### ARC-05. SCM-операции без абстракции — INFO (оставлено)
- **Где:** `winsys.go`.
- **Почему не меняли:** одна реализация; интерфейс ради моков проверял бы сам себя, а
  реальные риски (8 КБ binPath, WinDivert, коды выхода winws) моки не воспроизводят.
- **Когда менять:** если появится второй бэкенд или регрессии в оркестрации подбора.

### ARC-06. Неиспользуемый результат `updateRelease` — LOW
Возвращал `(bool, error)`, bool никто не читал (unparam). Теперь `error`.

## Что сознательно не делалось

- Clean/Hexagonal Architecture, DI-контейнеры, слои репозиториев — избыточны для ~4,5 тыс.
  строк с одной реализацией каждой операции.
- Перенос `main` в `cmd/` — сломал бы привычную сборку `go build .` без выигрыша.
- Метрики/OpenTelemetry/HTTP health endpoint — у desktop-службы нет потребителя метрик;
  наблюдаемость — журнал событий, `status`, `doctor`.

## Оценка связанности после изменений

| Пакет | Импортирует | Импортируется |
|---|---|---|
| `main` | все `internal/*`, x/sys | — |
| `internal/batch`, `version`, `safezip` | stdlib | main |
| `internal/hostsfile`, `zapretfmt` | stdlib, textutil | main |
| `internal/textutil` | stdlib | main, hostsfile, zapretfmt |
