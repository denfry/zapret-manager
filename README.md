# zapret-manager

Обёртка над [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) для Windows.
Это один exe: меню, консольная утилита и служба-сторож.

## Скачать и поставить

**[Скачать zapret-manager.exe](https://github.com/denfry/zapret-manager/releases/latest/download/zapret-manager.exe)**
(последняя версия; [все релизы](https://github.com/denfry/zapret-manager/releases)).

1. Запустите exe двойным щелчком и разрешите запрос прав администратора — откроется меню.
2. Выберите **«Установить»**. Программа скопирует себя в `C:\zapret`, скачает zapret, подберёт
   рабочую стратегию и включит автопочинку. Если zapret уже стоит через `service.bat`, его
   стратегия и настройки перенесутся. Дальше открывайте `C:\zapret\zapret-manager.exe`.
3. Вышла новая версия zapret-manager — скачайте её, откройте и выберите
   «Заменить установленный zapret-manager этим файлом».

```
zapret-manager 1.2.1 · папка C:\zapret
────────────────────────────────────────────────────────────────
 ● zapret       работает — стратегия general (ALT11), версия 1.10.4
 ● автопочинка  включена — сторож сам проверяет связь и чинит
 · охват        по спискам; сервисы: Instagram, X (Twitter); своих сайтов: 1
 ● проверка     08.11 14:02 — Discord 6/6, YouTube 4/4, остальное 5/5 — всё открывается

   1  Проверить, что открывается
   2  Что разблокировать: сервисы, свои сайты, все сайты, игры
   3  Подобрать лучшую стратегию
   4  Выбрать стратегию вручную
   5  Выключить zapret (на время или до включения)
   6  Обновить zapret, списки и hosts
   7  Подробный статус
   8  Журнал
   9  Диагностика (конфликты с VPN, антивирусами и т.п.)
  10  Удалить…
   0  Выход
```

Windows SmartScreen может написать «Windows защитил ваш компьютер»: exe не подписан
сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае». Проверить, что exe собран
GitHub Actions из исходников этого репозитория:
`gh attestation verify zapret-manager.exe -R denfry/zapret-manager`
(или сверить `Get-FileHash zapret-manager.exe` с файлом `.sha256` из релиза).

## Что делает

Что делает сам, без участия пользователя:

- **ставит zapret в службы** (`zapret`, как пункт Install Service в `service.bat`) и держит её запущенной;
- **обновляет zapret.** Раз в 6 часов смотрит `.service/version.txt`. Если вышла новая версия, качает zip,
  переносит свои списки, game filter и режим ipset. Ставит ту же стратегию и сравнивает работу с прежней версией.
  Если стало хуже, откатывается и помечает версию как нерабочую;
- **обновляет ipset** (`.service/ipset-service.txt`) и списки доменов из ветки `main`
  (`list-general.txt`, `list-google.txt`, `list-exclude.txt`, `ipset-exclude.txt`).
  winws сам перечитывает их при изменении файла, перезапуск не нужен;
- **обновляет hosts.** Блок Flowseal (github, telegram, discord) лежит между маркерами
  `# >>> zapret-manager … >>>` и `# <<< zapret-manager <<<`. Старые строки для тех же доменов, добавленные руками,
  убираются, чтобы на одно имя не было двух IP. Копия перед каждой правкой кладётся в `C:\zapret\backups`;
- **чинит, когда что-то отвалилось.** Раз в 5 минут делает настоящие запросы
  (TCP → TLS → GET, читает до 48 КБ, чтобы поймать «заморозку» на 16–20 КБ) к Discord, YouTube, включённым
  [сервисам и своим сайтам](#что-разблокировать) и контрольным ya.ru и vk.com. Если проверка не прошла
  3 раза подряд, действует так:
  1. перезапускает zapret;
  2. проверяет пять лучших стратегий из прошлого подбора;
  3. перебирает все стратегии, как «Run Tests» в `service.bat`, и ставит лучшую (тройку лидеров перепроверяет);
  4. если не помогло ничего, ищет новую версию zapret.

  Если не открываются и контрольные сайты, значит пропал интернет, и сторож ничего не трогает.
  Если все ошибки DNS или сертификата, значит провайдер подменяет DNS: стратегию не меняет, советует включить DoH.
  Если подборы подряд ничего не находят (например, лёг сам Discord), интервал растёт: 30 мин → 1 ч → 2 ч → 4 ч.
  Сервис или свой сайт, который на полном подборе не открыла ни одна стратегия, сторож сутки не чинит
  (в статусе он помечен «не помогает»): его режут не DPI, и перебор стратегий только мешал бы остальному;
- после выхода из сна проверяет через 20 секунд.

## Что разблокировать

zapret обрабатывает не весь трафик, а только то, что попадает в его списки. По умолчанию это
Discord, YouTube, немного доменов из списков Flowseal и подсети зарубежных хостингов (ipset).
Расширить охват — пункт меню «Что разблокировать» или команда `sites`:

- **сервисы из каталога** — `sites add instagram x`, все сразу — `sites add all`. Их домены
  дописываются в `lists\list-general-user.txt` (в отдельный блок между маркерами
  `# >>> zapret-manager …` и `# <<< zapret-manager <<<`), а адреса — в проверки сторожа:

  | Сервис | ID |
  |---|---|
  | Cloudflare и зарубежные хостинги (только проверка: их покрывает ipset) | `hosting` |
  | Instagram | `instagram` |
  | Facebook и Messenger | `facebook` |
  | X (Twitter) | `x` |
  | LinkedIn | `linkedin` |
  | RuTracker | `rutracker` |
  | Roblox (для самой игры — ещё `sites games all`) | `roblox` |
  | Signal | `signal` |

- **свои сайты** — `sites add example.com` (можно вставить ссылку целиком). Первые 10 тоже проверяются;
- **режим «все сайты»** — `sites mode all`: zapret обрабатывает соединения со всеми сайтами, кроме
  исключений. Открывает больше всего, но изредка ломает отдельные сайты. Вернуть как было — `sites mode lists`;
  `sites mode domains` — только домены из списков, без подсетей хостингов. Это пункт IPSet Filter
  из `service.bat` (any / loaded / none);
- **игры** — `sites games all|tcp|udp|off`: game filter из `service.bat`, порты 1024–65535 для подсетей
  из ipset (в режиме «все сайты» — для всех адресов). Меняет командную строку службы, стратегия
  переставляется сама;
- **исключения** — `sites exclude bank.example`: zapret этот сайт не трогает (`list-exclude-user.txt`).
  Нужны, если с zapret какой-то сайт перестал открываться; `sites include` — убрать.

Всё это хранится в файлах релиза, которые читает и `service.bat`, и переезжает в новую версию
zapret при обновлении. После изменения zapret перезапускается, а программа сразу проверяет, что открывается.

zapret **не поможет**, если сервис сам не пускает из России (ChatGPT, Gemini, Claude, Spotify, Netflix…),
если адрес закрыт по IP целиком или провайдер подменяет DNS (тогда — DNS-over-HTTPS). Тут нужен VPN.

## Установка из командной строки

Пункт меню «Установить» — это команда `install`. Её можно выполнить и напрямую
(exe из релиза или собранный из исходников):

```powershell
go build -trimpath -ldflags "-s -w" -o dist\zapret-manager.exe .
dist\zapret-manager.exe install
```

`install` попросит права администратора и сделает следующее:

1. закроет папку `C:\zapret` (другая папка: `--dir D:\zapret`) на запись для всех, кроме
   администраторов и SYSTEM, и скопирует себя туда. Папка должна быть пустой, своей или с
   распакованным релизом zapret — в папку с чужими файлами `install` ставить откажется;
2. найдёт уже стоящую службу `zapret` (например, из папки на рабочем столе) и запомнит стратегию,
   `*-user.txt`, game filter и режим ipset;
3. скачает последний релиз в `C:\zapret\releases\<версия>` и перенесёт туда эти настройки;
4. обновит ipset, списки и hosts;
5. переставит службу `zapret` на новую папку с той же стратегией и проверит. Если стратегия не работает, подберёт;
6. поставит и запустит службу-сторож `zapret-manager`.

Флаги: `--strategy ALT11` — сразу нужная стратегия, `--select` — подобрать заново, `--from ПАПКА` —
откуда переносить настройки, `--no-watchdog` — без сторожа.

## Команды

| Команда | Что делает |
|---|---|
| `menu` | меню по пунктам (открывается и двойным щелчком по exe) |
| `status` | версия, стратегия, службы, последняя проверка, подбор и события (права админа не нужны) |
| `check [-v]` | проверить сейчас Discord, YouTube и включённые сайты |
| `sites` | что разблокирует zapret и каталог сервисов (права админа не нужны) |
| `sites add\|remove СЕРВИС\|ДОМЕН …` | включить/выключить сервис из каталога (`all` — все) или свой сайт |
| `sites mode all\|lists\|domains` | все сайты / по спискам (как в Flowseal) / только домены |
| `sites games off\|all\|tcp\|udp` | игры (game filter) |
| `sites exclude\|include ДОМЕН …` | не трогать сайт / вернуть |
| `select [--quick] [--dry-run]` | перебрать стратегии и поставить лучшую (сайты пару минут будут мигать) |
| `use ALT11` | поставить стратегию вручную |
| `list` | все стратегии с результатами последнего подбора |
| `update [--force]` | обновить zapret, ipset, списки и hosts прямо сейчас |
| `hosts` | обновить только hosts |
| `off [минуты]` / `on` | выключить zapret (например, для игры с античитом). Без минут — до `on`, переживает перезагрузку |
| `doctor` | диагностика, как Run Diagnostics в `service.bat`, плюс VPN-туннели и системный прокси |
| `log [N]` | журнал `C:\zapret\logs\manager.log` |
| `uninstall [--all]` | убрать сторожа (`--all` — ещё службу zapret, WinDivert и блок в hosts) |

Двойной щелчок по exe открывает меню и один раз просит права администратора на всё меню.
Каждый пункт меню — одна из команд выше с теми же параметрами. Из командной строки без
аргументов программа показывает справку и статус.

## Как устроено

```
C:\zapret\
  zapret-manager.exe
  config.json        настройки (см. ниже)
  state.json         последняя проверка, подбор, версии
  releases\1.10.4\   релизы Flowseal как есть; service.bat в них продолжает работать
  custom\            свои стратегии *.bat (участвуют в подборе наравне с general*.bat)
  backups\           копии hosts
  logs\manager.log
```

Стратегия — это `general*.bat`. Программа разбирает строку `winws.exe` так же, как её выполнил бы `cmd`:
подставляет `%BIN%`, `%LISTS%`, `%GameFilter*%`, склеивает переносы `^`, превращает `^!` в `!`.
Получившаяся командная строка идёт и в `binPath` службы, и в тестовый запуск.
Тест сверяет её с тем, что прописывает `service.bat`: 176 аргументов ALT3 совпадают один в один.

Настройки самого zapret остаются там же, где их ищет `service.bat`: `utils\game_filter.enabled`,
`lists\ipset-all.txt`, `lists\*-user.txt`. Пункты меню Game Filter и IPSet Filter в `service.bat` текущего релиза
продолжают работать, сторож подхватит изменения. Стратегию, поставленную через `service.bat` → Install Service,
он тоже примет как текущую.

Во время подбора тестовый winws сидит в Job Object: если программа упадёт, он умрёт вместе с ней,
а сторож поднимет службу zapret на следующей проверке.

Обе службы работают от SYSTEM, поэтому менять файлы в `C:\zapret` может только администратор:
иначе любая программа без прав подменила бы winws.exe или стратегию. Свои стратегии в `custom\`
и `config.json` правьте из редактора, запущенного от администратора. Служба-сторож при старте
проверяет права на папку и, если их ослабили, исправляет. `status`, `check`, `list` и `log`
работают и без прав администратора (только `check` тогда не сохраняет результат).

## config.json

```json
{
  "auto_heal": true,              // сам чинить, когда Discord, YouTube или включённые сайты отвалились
  "auto_update": true,            // сам ставить новые релизы
  "update_ipset": true,
  "update_lists_from_main": true,
  "update_hosts": true,
  "check_interval_sec": 300,
  "update_interval_hours": 6,
  "min_sweep_interval_min": 30,
  "failures_before_heal": 3,
  "healthy_ratio": 0.75,          // какая доля адресов группы должна открыться
  "keep_versions": 2,
  "repo": "Flowseal/zapret-discord-youtube",
  "branch": "main",
  "exclude_strategies": ["general (ALT8)"],
  "targets": [                    // свои адреса вместо стандартных Discord/YouTube/control
                                  // (сервисы и сайты из `sites` добавляются к ним); group: discord | youtube | control | любое
    {"name": "Discord", "url": "https://discord.com/", "group": "discord"}
  ]
}
```

Конфиг перечитывается на каждой проверке, сторожа перезапускать не нужно. Недопустимые значения
(интервал меньше минуты, `repo` не вида `владелец/репозиторий`, адрес проверки не `http(s)://…`)
заменяются значениями по умолчанию, предупреждение пишется в журнал. Допустимые диапазоны —
в [docs/deployment](docs/deployment/README.md#конфигурация).

## Ограничения

- Голос Discord (UDP 50000–50100) по HTTP не проверить. Если сайт и чат открываются, а голос нет —
  `select` или `use` с другой стратегией вручную.
- QUIC (HTTP/3) не проверяется: проверки идут по TCP, как и в тестах `service.bat`.
- Что уходит в VPN-туннель (Happ, Amnezia и т.п.), идёт мимо zapret. Проверки это учитывают как есть:
  если YouTube или Instagram открывается через VPN, он считается рабочим.
- Каталог сервисов — то, что в России обычно режут DPI. Помогает ли zapret у вашего провайдера,
  показывает проверка: что не открыла ни одна стратегия, помечается «не помогает».
- Подлинность релизов Flowseal проверяется только через HTTPS GitHub: подписей Flowseal
  не публикует. Это то же доверие, что и при ручной установке zapret.
